## Convenções

- Use `Ilustracao_` para elementos compostos e `Icone_` para elementos pontuais.
- Mantenha os nomes de trabalho em PascalCase com sublinhado para facilitar a
  busca pelos IDs e a correspondência com o Figma.
- Use os PNGs sem esticar a proporção original. Para os elementos compostos,
  preserve também a área externa do asset ao posicioná-los no infográfico.
- A origem visual é o Figma; qualquer alteração de cor, recorte ou composição
  deve ser registrada no arquivo de trabalho do infográfico.
