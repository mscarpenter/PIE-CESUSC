## Especificação visual para montagem

- **Canvas recomendado:** 1200 × 2200 px; para impressão A4, usar 1240 × 1754 px.
- **Fundo:** `#F5F2EB`; margens laterais de 60 px; grid de 12 colunas com
  gutter de 16 px.
- **Cores:** título `#14171A`; corpo `#33373D`; azul `#2A405A`; terracota
  `#D05A3F`; verde sálvia `#52735B`; divisórias `#DED7CB`; cards `#FFFFFF`.
- **Tipografia:** Plus Jakarta Sans; títulos em pesos 800–900 e corpo em peso
  500. Ajustar o tamanho do rodapé para manter todas as fontes legíveis.
- **Assets:** usar os componentes exportados em [assets/componentes](assets/componentes),
  preservando suas proporções originais.
- **Hierarquia:** cabeçalho no topo; tripé e dinâmica dialógica no primeiro
  bloco; protagonismo, troca de saberes e comparativo no bloco central; síntese,
  fontes e equipe no rodapé.
- **Exportação:** revisar a leitura em uma página antes de exportar em PDF ou
  PNG para a apresentação.

## 6. Dicas de Ouro para a Montagem no Figma

1. **Auto Layout no Figma:** Use Auto Layout (`Shift + A`) com `gap: 24px` no frame pai para manter o fluxo vertical consistente e uniforme.
2. **Escala das Imagens:** Ao redimensionar os PNGs da pasta `componentes`, segure `Shift` para nunca distorcer a proporção original.
3. **Profundidade sem Poluição:** Para destacar os cards ou o anel central, use sombras sutis no Figma: `X: 0, Y: 4, Blur: 16, Spread: 0, Color: #1A1A1A a 5%`.
4. **Exportação Final:** Exporte o frame principal como **PDF** ou **PNG @2x / @3x** para garantir nitidez máxima na apresentação.
